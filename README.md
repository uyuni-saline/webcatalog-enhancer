# WebCatalog Enhancer

用于增强 Comike Web Catalog 浏览与信息整理体验的 Tampermonkey 用户脚本。

## ✨ 主要功能

### ⭐ 收藏页

- 从社团详情页动态取得摊位、场馆、社团、作者及外部链接信息。
- 将社团名替换为包含日期、场馆和摊位编号的完整文本，并提供“摊位”“社团”“作者”三个独立复制按钮；其中社团名和作者字段会清理不适合用于文件名的字符，摊位信息保持原样。
- 将 X、Pixiv、主页、Melonbooks 和 BOOTH 显示为标准链接，支持中键打开新标签页和右键复制链接。
- 缺少 Melonbooks 或 BOOTH 链接时保留灰度图标占位，保持页面排列整齐。
- 收藏备注中存在 X/Twitter 链接时优先使用该链接；备注中没有有效链接时再使用详情页链接。
- 移除 Niconico 和 CLIP STUDIO 按钮。

### 🏷️ 社团详情页

- 按第1日和第2日的独立映射，在东、西、南区域后补充具体场馆编号。
- 保留原有全角摊位字母与 a/b 侧标；无法匹配场馆时使用 `?` 标记。
- 生成可单击复制的组合摊位信息，以及不含摊位编号的社团和作者信息。社团和作者文本发生清洗时，会并排显示清洗前文本和红色的清洗后文本。
- 原页面缺少 X 链接时，从备注中识别链接并激活原有灰色图标，同时切换为彩色图标。

### 🖨️ 印刷页

- 使用带场馆编号和清洗后社团信息重组文本，单击即可复制；摊位信息本身保持不变。
- 在「メモ」栏显示 Pixiv、X、主页、Melonbooks 和 BOOTH 按钮；缺少链接时使用灰度图标占位。
- 导出 CSV，包含摊位、社团、作者、备注、颜色、社团详情页及上述五类外部链接。

## 📥 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 等用户脚本管理器。
2. [点击这里安装 WebCatalog Enhancer](https://raw.githubusercontent.com/uyuni-saline/webcatalog-enhancer/main/webcatalog-enhancer.user.js)。
3. 在用户脚本管理器显示安装页面后确认安装。

## 🔄 更新

脚本管理器会按照自身的检查周期自动获取更新，也可以在管理器中手动检查新版本。
